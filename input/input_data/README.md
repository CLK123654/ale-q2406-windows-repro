# 发布窗口待处理批次

变更平台导出了发布通道、现有窗口、待排队请求和本轮事务计划。数据均为虚构内容，不对应真实客户、设备或生产变更单。

窗口时间使用UTC，区间左闭右开。同一lane_id下状态为ACTIVE的窗口不能重叠，端点相接允许。事务计划按文件顺序处理，其中交换窗口要在一次事务中完成，提交时仍有重叠的变更必须整笔回滚。取消窗口保留原记录，仅把状态改为CANCELLED。

通道出现空档时，同一时段的待排队请求按priority降序、requested_at升序和pending_id升序选择一项。时段仍被活动窗口占用时，不创建新窗口，并记录阻断原因。完整字段约定见contracts/window_contract.json。
